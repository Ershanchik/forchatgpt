# Introduction to Git and GitHub

## Simple Interest Calculator

This project demonstrates Git and GitHub basics and provides a Bash script for calculating simple interest from the principal amount, annual interest rate, and time period in years.

### How to use

```bash
bash simple-interest.sh
```

Enter:
- `p` — principal amount
- `r` — annual rate of interest (percentage)
- `t` — time period in years

Formula: **Simple Interest = p × r × t / 100**.

Example: principal `1000`, rate `5`, time `2` gives simple interest `100`.
